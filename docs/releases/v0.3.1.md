## Catalog updates

- The Windows desktop app and interactive CLI check for a signed catalog update in the background. After the first check, automatic checks run at most once every 24 hours.
- Use `llm-launcher update` or **Обновить список моделей** in Windows to check immediately. The CLI reports whether a new catalog was installed.
- The launcher starts with its bundled catalog or the newest verified local copy. Failed checks and older catalogs leave the current list available. The published catalog lives in this repository and can be updated independently of the launcher.
