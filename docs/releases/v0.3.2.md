## Interface languages

- The Windows desktop app opens in English by default. Use the language menu in the top right to switch among English, German, Russian, Simplified Chinese, and French. The interface updates immediately, keeps your current selections and prepared plan, and remembers the language for the next launch.
- The CLI command list and every command’s `--help` output are in English. The desktop activity journal can also show technical diagnostics in their original language.
