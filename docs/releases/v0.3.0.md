## What's new

- **52 launch profiles** across Ollama, vLLM, and llama.cpp. New options include Qwen3, Qwen3 Coder, Phi, Granite, Gemma, and gpt-oss. Recommendations show what the model is for and how much memory and disk space the profile needs.
- **llama.cpp catalog launches** on CPU or a compatible NVIDIA GPU. The launcher downloads a pinned GGUF file, checks its SHA-256 hash, and confirms GPU layer offload for CUDA plans.
- **Signed catalog updates** through `llm-launcher update` and the Windows **Обновить список моделей** button. A failed update leaves the current catalog available. The update server requires public access to the catalog files.
- **Better vLLM filtering** for BF16 and MXFP4 on NVIDIA. New vLLM plans keep `dtype=auto` for ordinary weights and `dtype=half` for AWQ. Smoke tests give reasoning models more room to return a final answer.

## Verification

Qwen3 0.6B Q8_0 was downloaded and run with llama.cpp on CPU in Docker. The API returned a text response. Automated tests checked catalog updates and model selection from 4 to 128 GiB on one simulated GPU. The new NVIDIA profiles and Windows desktop build still need a hardware run.
