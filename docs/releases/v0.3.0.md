# LLM Launcher 0.3.0

## Добавлено

- 52 профиля для чата, кода, ответов по переданному контексту и эмбеддингов. Среди них Qwen3 и Qwen3 Coder, Mistral, DeepSeek R1, Gemma, Phi, Granite, Llama и gpt-oss.
- Подбор для одной NVIDIA с 4–128 ГиБ VRAM с учётом свободной памяти, драйвера и формата весов.
- Подписанный каталог. В Linux список обновляется через `llm-launcher update`, в Windows через кнопку «Обновить список моделей».
- Профили llama.cpp для CPU и NVIDIA с загрузкой закреплённого GGUF, проверкой SHA-256 и пробным запросом.

## Изменено

- Рекомендации показывают практическое назначение модели и статус проверки.
- Подбор vLLM проверяет compute capability для BF16 и MXFP4 на каждой карте. Сохранены `dtype=auto` для обычных весов и `dtype=half` для AWQ.
- Проверочные запросы к Qwen3, DeepSeek R1 и gpt-oss оставляют больше токенов для рассуждений. Настройки DeepSeek R1 применяются также в новых профилях vLLM и llama.cpp.

## Проверено

Qwen3 0.6B Q8_0 скачана из Hugging Face и запущена в llama.cpp на CPU в Docker. Команда `test` получила текстовый ответ. Подбор для 4–128 ГиБ проверен на тестовых конфигурациях. Новые профили NVIDIA и Windows EXE требуют прогона на целевых машинах.
